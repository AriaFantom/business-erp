# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Stack

Single AdonisJS v7 app that serves an Inertia + React 19 SPA from the same process. Postgres via Lucid ORM, Redis for cache/sessions, S3-compatible storage (MinIO in dev), Vite + Tailwind v4 + shadcn (style: `radix-vega`, base color: `neutral`).

Node `>=24.0.0` is required.

## Common commands

All app CLI work goes through `node ace`. Long-form scripts:

- `npm run dev` — `node ace serve --hmr` (HMR for backend via hot-hook, Vite for frontend)
- `npm run build` — `node ace build`
- `npm start` — `node bin/server.js` (production)
- `npm test` — `node ace test` (runs all Japa suites)
- `npm run lint` — `eslint .`
- `npm run format` — `prettier --write .`
- `npm run typecheck` — typechecks both root and `inertia/tsconfig.json`

Single test / suite:
- `node ace test --suites=unit` (or `functional`, `browser`)
- `node ace test --files="path/to/file.spec.ts"`
- `node ace test --grep "test name pattern"`

Database (Lucid):
- `node ace migration:run` — applies migrations **and regenerates `database/schema.ts`**
- `node ace migration:rollback`
- `node ace make:migration <name>`

Local infra: `docker-compose -f docker-compose.dev.yml up -d` brings up Postgres (`dev/dev/dev` on 5432), Redis (password `dev` on 6379), and MinIO (9000 API / 9001 console, `devminio/devminio`). Match these creds in `.env` (see `.env.example`).

## Architecture

### Backend layout (`app/`, `start/`, `config/`, `providers/`)

- `start/routes.ts` — all HTTP routes; controllers are referenced via the auto-generated `#generated/controllers` registry (from `indexEntities`). The route file groups public `signup`/`login` under `middleware.guest()` and `logout` under `middleware.auth()`.
- `start/kernel.ts` — middleware stacks. Server stack includes Inertia, Vite, CORS, static. Router stack adds bodyparser, session, shield, auth init, and `silent_auth` (so unauthenticated requests still resolve `auth.user` if a session exists). Named middleware: `guest` and `auth`.
- `app/middleware/inertia_middleware.ts` — extends the framework middleware to share three props on every Inertia render: `errors` (validation), `flash` (`error`, `success` from session flash), and `user` (run through `UserTransformer`). Always run model data through transformers before sharing.
- `app/models/user.ts` — User extends `compose(UserSchema, withAuthFinder(hash))`. **`UserSchema` is generated by Lucid into `database/schema.ts` from migrations — do not edit that file.** Add custom fields/methods to the model class, not the schema.
- `app/transformers/` — extend `BaseTransformer` and call `this.pick(this.resource, [...])` for serialization. These work with the custom ApiSerializer.
- `providers/api_provider.ts` — registers `ctx.serialize(data)` on every `HttpContext`. Wraps responses in `{ data: ... }` and validates Lucid pagination metadata. Use `ctx.serialize(...)` (or `ctx.serialize.withoutWrapping(...)`) in controllers that return JSON instead of returning raw arrays/objects.
- `app/validators/` — VineJS validators. Controllers consume them via `request.validateUsing(theValidator)`.
- Auth uses session guard only (`config/auth.ts`); `useRememberMeTokens: false`.

### Path aliases

The `#prefix/*` Node subpath imports (defined in `package.json` `imports`) cover backend code:
`#controllers`, `#models`, `#middleware`, `#services`, `#validators`, `#transformers`, `#policies`, `#abilities`, `#database`, `#start`, `#config`, `#tests`, `#mails`, `#events`, `#listeners`, `#providers`, and `#generated/*` → `.adonisjs/server/*` (auto-generated by `indexEntities`/`indexPages`/`generateRegistry` hooks in `adonisrc.ts`).

Frontend aliases (`vite.config.ts`):
- `@` and `~/` → `inertia/`
- `@generated` → `.adonisjs/client/` (Tuyau registry, shared-prop types as `Data.SharedProps`)

### Frontend (`inertia/`)

- `inertia/app.tsx` — Inertia entry. Pages live under `inertia/pages/**/*.tsx` and are auto-resolved by name (e.g. `inertia.render('auth/login')` → `pages/auth/login.tsx`). Every page is wrapped by `inertia/layouts/default.tsx`.
- `inertia/client.ts` — Tuyau client created from `@generated/registry`. Use `urlFor` for type-safe URL generation in components.
- `tuyau` runs as an `init` hook (`generateRegistry()` in `adonisrc.ts`), so the client registry stays in sync with backend routes/controllers.
- SSR is configured but disabled (`vite.config.ts`: `ssr.enabled: false`).
- shadcn settings in `components.json`; UI primitives go under `inertia/components/ui/`. Icon library is `lucide-react`. Styles in `inertia/css/app.css`.

### Hot reload boundaries

`package.json#hotHook.boundaries` limits HMR module replacement to `app/controllers/**/*.ts` and `app/middleware/*.ts`. Editing models, services, providers, or config requires a full restart.

### Tests

Japa runner with three suites declared in `adonisrc.ts`:
- `unit` — `tests/unit/**/*.spec.{ts,js}` (2s timeout)
- `functional` — `tests/functional/**/*.spec.{ts,js}` (30s)
- `browser` — `tests/browser/**/*.spec.{ts,js}` (300s, uses `@japa/browser-client`)

`tests/bootstrap.ts` is the only file present — add new specs under the appropriate suite directory.
